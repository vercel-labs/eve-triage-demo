# eve triage demo

A small TypeScript project with a few intentional bugs, used by the [eve triage agent quickstart](https://eve.dev/docs/getting-started/triage-agent). The bugs are reported in this repository's issues. It is adapted from [harness-triage-repro-bugs](https://github.com/vercel-labs/harness-triage-repro-bugs).

Select **Use this template** to make your own copy, then open issues on it for your triage agent to investigate.

## Run the tests

Requires Node.js 24 or newer. There are no dependencies to install.

```bash
npm test
```
